The Harvester is a large Swedish machine built around a single big rocket pod on its back and a body packed with Core Drives. It backs that up with concussion pulses, neurotoxin gas and, in the later classes, its own Ticks.

The game files call it harvester. It comes in 4 classes with 8 distinct layouts between them; total component health ranges from 4,725 to 11,256.6.
