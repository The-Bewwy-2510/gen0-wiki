Where the information comes from

We made our own extraction tool that opens Generation Zero's game files and reads out the data the game itself uses: weapon damage, machine health, skills, schematics, missions, items, map positions and more. The wiki pages are built from that data automatically.

That means the numbers here are not guesses or copied from older guides. When the game is updated, the data is read again and the pages are rebuilt.

From the game files
Where the current game files disagree with something older guides still say, the page points it out in a green Corrected box. A few things, like some special ammo effects, aren't stored where the tool can read them; the pages say so where it matters.

Pictures

Item icons, map art and other game images come from Generation Zero itself and belong to Systemic Reaction and Avalanche Studios Group; they are shown here for reference.

The pictures of the machines were rendered for this wiki from the game's own 3D models, which the extraction tool reads out of the game files together with their animations; each machine type is shown in one of its own in-game poses.

The machine pictures listed below are still from the Generation Zero Wiki on Fandom, used under the CC BY-SA licence, until their renders are done.

The DLC pictures and descriptions on the DLC page are from the Steam store.
