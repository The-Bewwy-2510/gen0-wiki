About this wiki

This wiki is generated from data extracted from Generation Zero's own files, and styled after the Gen0 tools (the save editor, mod maker, extractor and map). It is a fan project and is not affiliated with Systemic Reaction or Avalanche Studios Group.

Where the numbers come from

Read from the game's own tuning files (layout .epe files, .ammotunec projectile tuning, .ftunec blast tuning, weapon_tuning.bin and difficulty_settings) using the DECA-Dec-26 extractor, and machine senses from settings/hp_settings/animal_senses.bin.

Item names, mission texts, skills, schematics, apparel and locations come from the game's item tables, text tables, mission files and map location files, read by the Gen0 Editor and Extractor. Map positions are the game's own world coordinates (metres).

Some effects aren't in the files the extractor reads – for example the special effect of some experimental ammo lives in a separate effect file. Pages say so where it matters.

Corrections

When a value here disagrees with an older guide, the game files win: they are what the game actually uses. Green Corrected boxes point out the most common outdated numbers. If you find a mistake on this wiki, open an issue or pull request on GitHub.

Updating the wiki

The site is plain HTML generated by a Python script (no dependencies):

  1. Re-extract the data with the Gen0 tools after a game update.
  2. python build/import_sources.py --tools ../gen0-tools --mapping ../gen0-mapping --stats "Machine & Weapon Stats.json" --loadouts "Machine Loadouts.json"
  3. python build/build.py — writes the site into docs/ and checks every link.
  4. Commit and push; GitHub Pages publishes docs/.
