Skilled Spotter

Skilled Spotter is a Support augment. The game describes it as: “Marks machines when destroying a component.”

One counter is shared by all three tiers. “Counter” is the value that unlocks the tier, “more” is how much further that is from the tier before it; the task text is the game's own for that threshold.

TierCounterMoreTask
Bronze00Unlocked from the start
Silver5050Mark a machine 50 times.
Gold200150Mark a machine 200 times.
Tip
The Bronze threshold is 0, so Bronze counts as researched from the start: you only need to unlock its design at a crafting station.
