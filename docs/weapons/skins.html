From the game files
Status is the unlock flag the game's vanity table carries for each skin: Starts unlocked (every profile has it), Starts locked (you have to get it in the game; the files don't say how), DLC (unlocked as soon as you own the pack) and DLC, earned (starts locked even with the pack). “Pack” is the content pack the item belongs to, which is not always the same thing: a skin can sit in a DLC's content pack and still be flagged as starting unlocked. Weapons not listed here have no skins.
