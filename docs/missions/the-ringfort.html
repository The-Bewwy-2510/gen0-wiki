Briefing

The mission log text, as the game shows it.

You found someone stuck in the basement of a villa on Måsskär; unfortunately, he seems to be the sole survivor, and what used to be the new settlement of Måsskär is now nothing more than rubble. The magnitude of the destruction and the size of the craters seem to indicate FNIX was able to create a new weapon of great firepower.

Is it worth rebuilding a new shelter in the same spot, if it can be effortlessly razed to the ground in a few minutes? It's time to start from scratch, somewhere else, and to build a new camp for you and that survivor.
