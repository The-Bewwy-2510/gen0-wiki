Briefing

The mission log text, as the game shows it.

With the limited hardware she still has in the tunnels, Veronika wrote a computer virus that should override the machines' artificial intelligence. Due to the situation, she had to rely on her own photographic memory to remember the code she wrote before the Cataclysm, and was never able to test the virus on machines herself.

She entrusted you with the only prototype she made: use this modified hacking device to inoculate Veronika's test virus into FNIX's system. If this works, all might not be lost for the Resistance - for humankind.
