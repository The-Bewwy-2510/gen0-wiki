Briefing

The mission log text, as the game shows it.

There are rumors of new machines appearing in the northern parts of Östertörn. A possible new threat that no one knows much about.

The Resistance has set up an outpost in the outskirts of the Marshlands. There may be more information about the machines there, or maybe you can help them find out more. Information about these new machines needs to be shared as quickly as possible; anyone currently in the Marshlands region could make a big difference in helping everyone learn more.

Objectives6 required · 1 optional

The objectives in the order of the mission log. After names the objectives that have to be done first, opens with the ones that become available at the same time (they can be done in any order); ×N is how many times the game counts the objective. Some objectives also wait on hidden script steps (cut scenes, radio calls, spawns) that are not listed, so a step without an after may still have to wait for one of those.
