Briefing

The mission log text, as the game shows it.

The Warboard you discovered in "Vesslan" (Swedish for "weasel") revealed the existence of 6 other Command Bunkers scattered across the area. In accordance with established counter-intelligence military protocol, knowledge of their location was strictly compartmentalized. The only indication you have is their code names.

Discover the other Warboards in each Command Bunker to find new Main Missions and activities.
