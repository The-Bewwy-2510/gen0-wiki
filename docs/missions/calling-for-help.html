Briefing

The mission log text, as the game shows it.

According to the Warboard, Vesslan Command desperately tried to keep in touch with a nearby military base during the first couple of days of the Cataclysm. It is indicated to contain a radio mast, and as such was a key strategic location to defend.

Find out where this military base is located, then try to use its radio mast to contact the outside world or make a distress call.

Objectives6 required

The objectives in the order of the mission log. After names the objectives that have to be done first, opens with the ones that become available at the same time (they can be done in any order); ×N is how many times the game counts the objective. Some objectives also wait on hidden script steps (cut scenes, radio calls, spawns) that are not listed, so a step without an after may still have to wait for one of those.

  1. Listen to the emergency phone call inside Vesslan Bunker
  2. Locate and reach the Saltholmen military base
  3. Clear the enemies guarding the Saltholmen base×5after 2
  4. Find a radio to investigate the signal disruption
  5. Get rid of the source of the disruption
  6. Use the radio again to call for help
