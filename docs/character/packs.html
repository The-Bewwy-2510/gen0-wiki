Item packs

The game files sort content into content packs, each known by a hash. This page lists all 27 packs that appear in the vanity list and in the key and item lists, with everything that belongs to each. The data names only three of them: the base game, Alpine Unrest and FNIX Rising. The other 24 have no name in the files, so the names here are inferred from their contents and marked as such. The weapon DLC packs, which the weapon stats name but without a hash, are listed at the end.

From the game files
A content pack is not always a paid DLC. The lock flag is set per item: items that start locked (flag L) are things you earn or find in the game, like rewards and event items, and items with the D flag are downloadable content. Some packs mix flags; the Lock flags line of each pack below lists them. The Gen0 Editor reads a profile's owned packs from the items it has unlocked and the items the game set aside as inaccessible.

Lock flags

Every vanity item has a lock flag. The first letter is its starting state, a trailing D marks downloadable content. A pack's flags tell you how you get its items. No game file defines the letters; the meanings below are inferred from how the Gen0 Editor uses them. Heads and hands are chosen at character creation whatever their flag (they are all L).

FlagShown asMeaning
UStarts unlockedevery profile has it from the start
LStarts lockednot given automatically: found, earned, or chosen in the character creator
UDDLC, givendownloadable content that is unlocked as soon as you own the pack
LDDLC, earneddownloadable content that starts locked even when you own the pack
