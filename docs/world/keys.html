How keys work

Keys, barcodes, keycards and mission items don't take up space in your backpack. The game keeps them in your profile's item stash, which every character of the profile shares. There is no record of opened doors: holding the key is what opens its door. Items tagged Mission item are flagged as such in the files: a mission normally hands them out or asks for them.

Items of a DLC the account doesn't own are set aside by the game, so you can't use them. Missions that name it quotes the mission line that asks for the item.

Command bunker barcodes7

Each command bunker needs a full entry barcode, which the game splits into pieces: you can hold 3 pieces of each. You collect them from destroyed machines of that region (the Warboard missions say so), and a full barcode opens that region's command bunker. Activating the Warboards is the challenge The New Total Defense (activate the last 3 command bunker warboards for the last tier).
