Gen0 Map Editor

The Gen0 Map Editor shows every object placed in the Generation Zero world in 3D. You can select, move, turn, duplicate and delete objects, then build the changed location files into a dropzone mod and install or uninstall it in the game, with backups. It is a Godot 4 (C#) program laid out like Blender, with a Rendered view of the game's own models, ground, roads, plants and decals.

Installing and starting

  • Install with build\installer\Gen0 Map Editor Setup <version>.exe (made by editor\Build installer.bat). Your changes, the world cache, builds and backups are kept in %LOCALAPPDATA%\Gen0 Map Editor.
  • Start it from the Start menu / desktop shortcut, or with Run without building.bat (also what the Tools Hub uses): it starts the installed program, or the project in Godot when it isn't installed.
  • The first time, it asks where Generation Zero is installed (the folder with archives_win64 in it), and loading the world reads every location in the game, which takes about a minute. Later starts use the world cache.
  • Coming from the old browser-based version (0.1 - 0.6, Python)? Remove old web version.bat clears out what it left, after moving your changes, backups and the installed-mod record to the new program.
Note
The game folder is only read. Build writes the mod into a dropzone folder and Install copies it into the game's dropzone, which needs the dropzone launch options.

Workflow

  1. Go to the place you want to change in the 3D viewport (orbit, pan and zoom, or walk mode), or search for a location by name (for example iboholmen).
  2. Select objects (click, box select) and move (G), rotate (R), duplicate (Shift+D) or delete (X) them, or type exact values in the properties panel. Add puts in a static model (building, rock, prop), an object (light, AI blocker, lootable, decal ...) or a whole place (church, farm, bunker ...).
  3. Check the change list on the right; Ctrl+Z / Ctrl+Shift+Z undo and redo.
  4. Build the mod: the changed location files are written as a dropzone mod.
  5. Install into the game (with backups), start the game with the dropzone launch options, and Uninstall to go back.

Every object has an _object_id; saves remember looted, destroyed and collected objects by it, and copies get new ones. So a duplicated loot crate is a new crate as far as your save is concerned.

Building from source

Needs the .NET 8 SDK or newer, Godot 4.7.2 .NET with its export templates, and Inno Setup 6. editor\Build installer.bat does three steps:

  1. Compiles the C# code (dotnet build App\Gen0MapEditor.csproj -c ExportRelease).
  2. Exports the Godot app to build\app\Gen0 Map Editor.exe.
  3. Makes the setup with Inno Setup into build\installer.

To run it from source, open editor\App in Godot, or run Godot_v4.7.2-stable_mono_win64.exe --path App.
