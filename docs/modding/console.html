gen0-console is a Generation Zero mod menu that opens in the game with F1. It is a fork of Generation Zero Console Thingy by jacee (MIT licence): everything the original console does still works, and the fork adds a loot highlight, longer render distance, a lock-height float, more saved toggles, and an experimental SteamVR mode.

Heads up
This mod modifies game memory and may lead to instability or crashes. Use it at your own risk and back up your saves.

Installing

With Gen0 VR (recommended)

Gen0 VR copies the console into the game folder, keeps a backup of what was there, and can uninstall it again cleanly. Untick Turn VR on for just the console. Uninstall can leave what was there before, the console without VR, or no console at all.

By hand

  1. Build the DLL (below) or take xinput9_1_0.dll from a release.
  2. Copy xinput9_1_0.dll into the Generation Zero folder, next to GenerationZero_F.exe.
  3. Start the game and open the console with F1.

Linux / Steam Deck: add WINEDLLOVERRIDES="xinput9_1_0.dll=n,b" %command% to the game's launch options. To go back to the original console, put the original console's xinput9_1_0.dll back.

Features by tab

The console has five tabs. Most switches act on the running game at once; the ones listed under saved settings are remembered between sessions.

Player

Health

  • Player invulnerable (all damage)
  • Revive player

Stamina

  • Infinite stamina (sprinting, jumping)

Inventory

  • Unlimited carry weight
  • Unlimited storage size
  • Infinite ammo
  • Infinite deployables & consumables
  • Unlimited resources (nothing used when building or crafting)

HUD

  • Hide HUD (F3)

Camera

  • Third person (F4; not while controlling a machine or vehicle)
  • Reset camera

Map

  • Enable fast travel anywhere

Machine interaction

  • Bullet damage multiplier (0.1 to 100, damage bullets do to machines)
  • Undetectable by machines
  • Faction

Base building

  • Unrestricted building (no collision checks, no building limits)
  • Command tokens (for claiming control points)

Vehicles

  • Infinite vehicle fuel
  • Vehicle acceleration & speed multiplier
  • No air resistance (much higher top speed)

Skills & experience

  • Player level
  • Experience
  • Skill points

Miscellaneous

  • First-person shadow (change clothes once for it to show)
  • Ignore deep water (travel underwater)
  • Ghost mode: float through everything without collision (F6; teleporting also ends it)

Machines

Spawning

  • Spawn any machine at your aim position, by category (host only; experimental)
  • Force spawn machines (also at positions the game wouldn't pick)
  • Spawn machines as friendly (instantly hacked)
  • Spawned machines disappear when you leave the area (intended)

Hacking

  • Hacking always succeeds
  • Unlimited hacking time
  • Advanced hacking (hacked machines always attack other enemies)

Targeted machine

  • Invulnerable
  • Kill
  • Health (%)
  • Faction (hostile to every other faction)
  • Control targeted machine (play as the machine)

Controlled machine

  • Unlimited signal strength
  • Control machine on hack
  • Release control
  • Invulnerable
  • Kill
  • Undetectable by other machines
  • Third-person camera distance (also the mouse wheel)

World

Events

  • Block automatic event scheduling
  • Select an event; shows the currently active ones

World time

  • Mirror real time (your system clock)
  • Time of day
  • Pause time
  • Time scale

Spawning

  • Spawn objects at your aim position by category, or any resource by tag / type ID (experimental; some stay until you exit to the menu). For more vehicles spawn a Vehicle Station from Buildings & Props.

Physics

  • World gravity (in G)
  • Player gravity (in G)
  • Zero / reset gravity

Teleportation

  • Teleport to X / Y / Z, use current position
  • Teleport to aim position (F2)
  • Predefined locations

Weather

  • Control weather: cloud density, transition time, manual downpour (rain without clouds), downpour, snow ratio (above 0.5 is snow), ground snow, snow randomness, ground wetness, lightning, cloud height and range, wind strength (2 to 8 works best)

GFX & filters

  • The game's graphics filter presets, Clear filter

Extra (fork)

Loot

  • Highlight nearby loot (F5): the game's own pickup outline on every lootable item and container within 5 to 50 m (default 7.5 m); looted containers are skipped

Render distance

  • Extra load range (0 to +3,000 m): towns, buildings and props stream in from further away (stock 250-500 m per location; the physics body limit is raised at game start)
  • Terrain detail distance (game default 256 m)
  • Detail level (LOD): 0 = game setting, 3 to 8 goes past the game's maximum (about 6 in VR)

Lock height

  • Float the player at a fixed height (F8); the height is editable. Not saved.

VR (experimental)

  • Enable VR, 3D on / off, recenter view, eye distance (1.00 = your headset's IPD), keep depth of field, sharpening
  • Advanced: head-tracked gun, gun uses headset FOV, mirrored head turns (flip Z), eye lag

Settings

Hotkeys

  • Rebind all eight hotkeys, reset to defaults

Console

  • Quicker startup (loads the main menu during the splash screens)
  • UI font scale
  • Developer mode (debug info and unfinished features)
  • Show the console hint

SteamVR mode

Plays Generation Zero in a SteamVR headset (developed on a Steam Frame). The mouse still aims; your head looks around.

  • Head tracking on the game camera.
  • True stereo: the scene is drawn twice per frame, once per eye, each with its own off-centre projection. The older alternate-eye mode (one eye per frame) is still there.
  • First-person gun follows the head and uses the headset field of view, so it is life-size and in 3D, and sights line up when aiming.
  • HUD (icons, prompts, menus) is carried into both eyes.
  • Depth of field is off in VR (it blurred the gun when aiming).
  • Per-eye TAA history so the game's anti-aliasing doesn't blend the two eyes (work in progress).

Setting it up

  1. Install with Gen0 VR and Turn VR on (or by hand: put openvr_api.dll from Valve's OpenVR SDK, bin/win64, next to the game's exe).
  2. Start SteamVR, then the game.
  3. In the game: Motion Blur off. In the console: Extra tab → VR → Enable VR.
  4. F7 recenters. Set Extra → Render Distance → Detail Level to about 6.

GZVR.txt

The VR settings live in GZVR.txt in the game folder. The console writes it from its Extra tab and the game re-reads it every second. A few of its keys, as the change notes describe them (the full list is at the top of src/game/custom/vr.h):

KeyWhat it does
on1 = VR on, 0 or no file = off
modestereo (true stereo, Gen0 VR's default), aer (alternate eye) or mono (flat screen)
recenterRe-centres the view
flipzHead-turn axis convention; 0 is the correct one
lagEye lag in frames for alternate-eye mode; 1 is correct (the picture runs one camera update behind), 0 swaps the eyes
gunFirst-person gun follows the head pose: 2 (default)
dof0 (default) turns depth of field off in VR, 1 keeps it
taaeyePer-eye anti-aliasing history: 2 (default)
dlss1 = NVIDIA DLSS upscaling per eye with mode=stereo (work in progress; needs nvngx_dlss.dll)
simreuse1 = the right eye skips view-independent passes already run for the left (opt-in)
Note
Alternate-eye 3D needs Motion Blur off and anti-aliasing on plain FXAA, because TAA and motion blur mix the eyes. The DLSS SDK is not in the repository (licence).

Files in the game folder

Everything the console and its VR mode use or write, all next to GenerationZero_F.exe. Gen0 VR's Uninstall clears the VR and research files and the crash dumps, leaves the xinput9_1_0.dll you choose (or none), and keeps GZConsoleThingy.ini and the console's logs\.

FileWhat
xinput9_1_0.dllThe console itself
GZConsoleThingy.iniIts settings and hotkeys

openvr_api.dll, nvngx_dlss.dllValve's OpenVR runtime, NVIDIA DLSS (optional)

GZTerrainExperiment.iniResearch hooks for terrain detail; a missing file or 0 has no effect
GZWatch.txtDeveloper memory watchpoint (addr=<hex>); addr=0 or deleting the file clears it
Crash dumps
The game's own crash reporter writes its dumps to %LOCALAPPDATA%\CrashRpt\UnsentCrashReports\ and deletes them when its window closes; the console's own dumps in logs\ stay.

Building from source

Needs Visual Studio 2022 (or the Build Tools, C++ workload) and CMake 3.16+. The dependencies (ImGui, MinHook, meow-hook, FW1FontWrapper) are in deps/, so there are no submodules.

cmake -B build -G "Visual Studio 17 2022"
cmake --build build --config Release
  • The DLL ends up in build/out/Release/Release/.
  • A post-build step copies it to C:/Program Files (x86)/Steam/steamapps/common/GenerationZero/; if your game is elsewhere (another Steam library or drive), point it there with -DGZ_GAME_DIR="D:/Steam/steamapps/common/GenerationZero", or turn the copy off with -DGZ_COPY_TO_GAME=OFF. The copy fails while the game is running.
  • -DGZ_VR=OFF builds the console without VR: no OpenVR, no GZVR.txt, no VR hooks or DLSS, and the VR controls are hidden. Everything else is the same.
  • Gen0 VR's Build VR mod.bat builds both versions from a mod-source checkout.

The repository's docs/CHANGES.md lists every change against gz-console-thingy v1.5.0 in detail, and docs/RENDERER.md holds the reverse-engineering notes on the game's renderer (frame structure, cameras, passes, terrain, crash signatures) for anyone writing a mod like this.
