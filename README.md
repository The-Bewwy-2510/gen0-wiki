# gen0-wiki

A wiki for **Generation Zero**, generated from data extracted from the game's own files: every weapon with damage
per ammo type and quality, every machine class and layout with component hit points, detection ranges, difficulty
scaling, all locations with mini maps, collectibles, missions, schematics, skills, apparel and modding guides.

It uses the look of the other Gen0 tools (the Tools Hub, Editor and Map) and is a plain static site, so it runs on
GitHub Pages with no build step on GitHub's side.

**Live site** (once Pages is on): `https://the-bewwy-2510.github.io/gen0-wiki/`

## Branches

- `wiki-overhaul`: the reorganised layout (v2): fluid width, a contents bar on the right that stays on screen,
  collapsible sections, map links that open the map with the page's filters, DLC and Achievements pages, and more.
- `main`: the original first version, kept unchanged just in case.

Pages serves whichever branch you pick in step 4 below.

## Turning on GitHub Pages

The finished site is in the `docs/` folder, so Pages only has to serve that folder:

1. Pick the branch to publish: `wiki-overhaul` (the new version) or `main` (the original).
2. Open **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**.
4. Set **Branch** to that branch and the folder to **`/docs`**, then **Save**.
5. Wait a minute or two. The address appears at the top of the Pages settings
   (`https://the-bewwy-2510.github.io/gen0-wiki/`). Every push to that branch republishes the site.

If the repository is private, Pages needs a paid GitHub plan; on a free account make the repository public
(**Settings → General → Danger Zone → Change visibility**).

## Browsing it locally

On Windows, double-click `Open wiki.bat` in a local clone if you have one (it runs the commands below). Otherwise:

Browsers don't let a page opened straight from disk load the search index and map files, so serve the folder:

```
cd docs
python -m http.server 8000
```

and open http://localhost:8000/.

## Rebuilding after a game update

The site is generated by Python 3 (standard library only):

```
# 1. copy fresh data from the other repos (after re-extracting it with the Gen0 tools)
python build/import_sources.py --tools ../gen0-tools --mapping ../gen0-mapping ^
    --stats "Machine & Weapon Stats.json" --loadouts "Machine Loadouts.json" --kinds ../gen0-dlc/data/kinds.json

# 2. regenerate docs/
python build/build.py
```

`build.py` prints the number of pages, any links to pages that don't exist and any missing images.
`python build/build.py weapons` rebuilds only one section while you work on it.

## Layout

| Path | What it is |
| --- | --- |
| `docs/` | the generated site that GitHub Pages serves (don't edit by hand; run the build) |
| `docs/img/` | item, skill, schematic, location and cosmetic icons (copied from the Gen0 Editor) |
| `docs/map/` | the interactive map ([gen0-mapping](https://github.com/The-Bewwy-2510/gen0-mapping)), also used for the mini maps |
| `build/build.py` | builds the site |
| `build/wiki/site.py` | page template, navigation, links, search index, helpers |
| `build/sections/*.py` | one module per part of the wiki (weapons, machines, world, missions, ...) |
| `build/static/` | the stylesheet, script, fonts (Open Sans, `OFL.txt`), logo and background |
| `build/data/` | the extracted game data the pages are made from |
| `build/SECTIONS.md` | how to write or change a section |
| `build/import_sources.py` | copies the data and icons in from the other Gen0 repos |
